# Калькулятор ячеек H3

Статическая страница: на карте (Leaflet + OpenStreetMap) рисуется область, а страница считает,
сколько в неё помещается ячеек [H3](https://h3geo.org).

Разрешение зафиксировано на **12**: средняя ячейка ≈ 307 м², то есть ≈ 3 256 ячеек на км²
(константа `RES` в `site/app.js`).

- **Многоугольник** — кликами расставить вершины; закрыть кликом по первой точке, двойным кликом или Enter.
- **Свободная рука** — зажать мышь (или палец) и обвести область.
- Можно нарисовать несколько фигур: пересекающиеся области не считаются дважды. «Удалить последнюю» и «Очистить всё» убирают фигуры.
- Что считать ячейкой области: центр внутри, ячейка целиком внутри или любое пересечение.
- Результат: число ячеек, площадь области и фактическая плотность (ячеек на км²).
- Ячейки рисуются на карте, пока их не больше 20 000. Если область даёт больше 600 000 ячеек (≈180 км²),
  вместо точного подсчёта показывается оценка по площади.

Библиотеки (`h3-js` 4.2.1, `leaflet` 1.9.4) лежат в `site/vendor`, сборки нет — это просто `site/index.html`.

## Локальный запуск

```sh
python3 -m http.server --directory site 8000
```

## Деплой на GitHub Pages

Workflow `.github/workflows/pages.yml` публикует папку `site/` при пуше в `master`.
Один раз включите в репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Адрес: `https://<owner>.github.io/<repo>/`.
