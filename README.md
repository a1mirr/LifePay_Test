# Калькулятор ячеек H3

Статическая страница: на карте (Leaflet + OpenStreetMap) рисуется область, а страница считает,
сколько в неё помещается ячеек [H3](https://h3geo.org).

Разрешение зафиксировано на **12**: средняя ячейка ≈ 307 м², то есть ≈ 3 256 ячеек на км²
(константа `RES` в `site/app.js`).

- **Многоугольник** — кликами расставить вершины; закрыть кликом по первой точке, двойным кликом или Enter.
- **Свободная рука** — зажать мышь (или палец) и обвести область.
- Можно нарисовать несколько фигур. Пересекающиеся фигуры **склеиваются в одну геометрию** (union, с учётом дырок),
  поэтому и ячейки, и площадь области считаются один раз, а не по сумме фигур. Непересекающиеся части считаются
  независимо, и уже посчитанные не пересчитываются при добавлении новых фигур.
- Что считать ячейкой области: центр внутри, ячейка целиком внутри или любое пересечение.
- Результат: число ячеек, площадь области и фактическая плотность (ячеек на км²).
- Ячейки рисуются на карте, пока их не больше 20 000.
- **Точный подсчёт больших областей.** До ≈180 км² (600 000 ячеек) считается точно всегда. Для больших областей
  по умолчанию показывается оценка по площади (`≈`), а переключатель «Точный подсчёт» запускает честный счёт
  с прогрессбаром и кнопкой «Отмена». Включение переключателя всегда пересчитывает все нарисованные фигуры заново
  (и маленькие тоже) и пишет в статусе, что подсчёт выполнен.
  Область режется на тайлы по ≈40 000 ячеек, каждый считается отдельным вызовом `polygonToCells`, на швах ячейки
  не дублируются (учитывается тайл, в котором лежит центр ячейки), поэтому итог совпадает с одним вызовом на всю
  область. Тайлы независимы и считаются параллельно в Web Workers (по числу ядер, максимум 16; `?threads=N` задаёт
  число потоков, `?threads=0` — счёт в основном потоке; если воркеры недоступны, например при открытии через
  `file://`, счёт идёт в основном потоке). Тайлы создаются лениво, поэтому размер области не ограничен.
- **Подсветка тайлов** во время точного подсчёта: серый — не посчитан, жёлтый — считается, зелёный — посчитан.
  Рисуется одним слоем canvas, состояния тайлов лежат в `Uint8Array`, поэтому подсветка работает для сетки любого
  размера (до 4 млн тайлов) и не тормозит интерфейс; рисуется только то, что попало в окно карты. Как только
  подсчёт закончился (или отменён), сетка убирается.
- **Очень большие области** (больше ≈50 млн ячеек, ≈15 000 км²): при включённом точном режиме один раз до перезагрузки
  страницы показывается предупреждение и точный режим выключается; если включить его снова, область любого размера
  считается без ограничений (отменить можно кнопкой «Отмена»).

Библиотеки (`h3-js` 4.2.1, `leaflet` 1.9.4, `polygon-clipping` 0.15.7) лежат в `site/vendor`, сборки нет — это просто `site/index.html`.

## Локальный запуск

```sh
python3 -m http.server --directory site 8000
```

## Деплой на GitHub Pages

Workflow `.github/workflows/pages.yml` публикует папку `site/` при пуше в `master`.
Один раз включите в репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Адрес: `https://<owner>.github.io/<repo>/`.
