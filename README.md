# Калькулятор площади H3

Статическая страница: на карте (Leaflet + OpenStreetMap) выбираются ячейки [H3](https://h3geo.org),
площадь считается точно через `h3.cellArea` (сферическая площадь каждой ячейки, а не среднее по разрешению).

- **Клик по ячейке** — добавить / убрать ячейку выбранного разрешения (0–12).
- **Рамка** — протянуть прямоугольник, добавятся ячейки, центры которых внутри (не больше 20 000 за раз).
- Ячейки разных разрешений можно смешивать: пересекающиеся не считаются дважды.
- Можно вставить готовые H3-индексы и скопировать индексы выделения.
- Результат: км², га, м², число ячеек и разбивка по разрешениям.

Библиотеки (`h3-js` 4.1.0, `leaflet` 1.9.4) лежат в `site/vendor`, сборки нет — это просто `site/index.html`.

## Локальный запуск

```sh
python3 -m http.server --directory site 8000
```

## Деплой на GitHub Pages

Workflow `.github/workflows/pages.yml` публикует папку `site/` при пуше в `master`.
Один раз включите в репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Адрес: `https://<owner>.github.io/<repo>/`.
